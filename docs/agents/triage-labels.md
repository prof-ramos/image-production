# Triage labels

Mapeamento dos cinco papéis canônicos usados pelas skills de engenharia:

| Papel canônico | Rótulo no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Aguarda avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informações do solicitante |
| `ready-for-agent` | `ready-for-agent` | Especificado e pronto para execução por agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será executado |

Quando uma skill citar um desses papéis, use o rótulo correspondente. Preserve os
rótulos existentes que tenham outras funções. Estar pronto para agente não amplia
as permissões nem o escopo da tarefa.
